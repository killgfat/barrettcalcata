# 可选晶体型号清单

本表是 worker 内置的 ULIB 优化常数快照（2016-10-31，共 304 款），
与 `GET /api/iol-models?formula=<非 Barrett 公式>` 返回的是同一份数据。
本 skill 默认查本表作为静态参考——读完表就能直接构造 `iol_model`，
不必先调接口。

**本表不含 Castrop 公式的 C/H/R。** 该公式 2021 年才发表，而 ULIB 快照
2016 年就停更了，表里没有这三列；服务端对 `?formula=castrop` 也
返回空列表，Web UI 在 Castrop 下不显示型号选择器。Castrop 的常数请按
SKILL.md「Castrop 的常数怎么取」处理，从 IOLCon 现取后用
`castrop_constants` 或 `castrop_elp` 传入。

需要服务端视角时（例如要 Barrett 官网那 18 个型号，或想要带 `match`
说明的映射结果）：

    curl -s "$IOL_API_BASE/api/iol-models?formula=barrett"
    curl -s "$IOL_API_BASE/api/iol-models?model=AMO%20ZCB00"

## 怎么用

- 把「型号」列的**完整名称**作为 `POST /api/calculate` 请求里的
  `iol_model` 字段；名称区分大小写，空格要原样保留。
- 命中后该型号的优化常数优先于请求里的同类常数
  （`a_constant` / `haigis_constants` / `hoffer_q_pacd` /
  `holladay1_sf` 会被屏蔽，
  详见 SKILL.md「常数优先级：型号赢」）。
- 「备注」列标 `prelim` 的是 ULIB 标记为 preliminary 的条目——
  样本量偏小、参考性较低，用到时应如实告知用户。
- **pACD 列有 3 款超出请求参数的 0~8 mm 校验**：`Alcon MA60MA (+diopters)`
  15.94、`(-diopters)` -5.52、`MIRA HI-MY (****)` 9.61。它们能通过
  `iol_model` 查表使用（服务端不做二次校验），但**手工抄成
  `hoffer_q_pacd` 传会被 400 拒绝**。这 3 款都超出薄透镜模型适用范围，
  实际算下去通常报「无法生成 IOL 度数表」；遇到时如实说明，不要硬凑。
  Holladay 1 的 SF 边界已放宽到 -10~12，正好容得下同批型号的 -7.08/+10.29。
- **Barrett 系列**（`barrett_ii_offline` / `barrett_ii`）不读本表，
  只用 `a_constant`；表里的 A 常数对 Barrett 仅作换算起点。
- 公式与常数的对应：SRK/T 用 A 常数；Hoffer Q 用 pACD；
  Holladay 1 用 SF；Haigis / Haigis-Toric 用 a0/a1/a2。
- **SF** 列是 Holladay 1 的 Surgeon Factor（mm），可直接作为
  `holladay1_sf` 传进请求，或声明 `iol_model` 让服务端自己取。
  它与接口里的 `sf` / `holladay1_sf` 是同一个数。
  **本表的 SF 与 IOLCon 的 optimized SF 不是同一来源**，数值会差：
  ZCB00 在本表是 2.02，IOLCon 的 nominal 是 1.96、optimized 是
  2.0582。本表是 2016 年 ULIB 快照，能拿到 IOLCon 时优先用 optimized。注意 SF 与 pACD 量纲
  相同但含义不同，不能互换：SF 是虹膜平面到 IOL 主平面的距离，
  pACD 是角膜顶点到虹膜平面的距离。

例如用 SRK/T 算 Alcon SN60WF：`iol_model` 填 `Alcon SN60WF`，
A 常数由本表给出，不需要再在请求里塞 A 常数。
