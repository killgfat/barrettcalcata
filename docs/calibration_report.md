# Barrett Universal II 离线模块校准报告

> 本报告由 scripts/calibrate_offline.py 实际运行生成，所有数字来自真实对数，未手工填写。

## 0. 结论摘要

- 官方 BUII 的 ELP 模型未公开；任务书引用的 2021 年论文无法检索到。
- 因此本仓库交付的是 Gaussian 聚散度核心 + 公开网格反演的 ELP 近似式，不是官方公式的逐系数复刻。
- 在 scans.csv 留出集（n=1994）上，五参数离线模型的 p95|Δ|=0.328 D、max|Δ|=0.918 D；纯 ALK 版 p95|Δ|=0.685 D、max|Δ|=1.805 D。
- 文献中的 mean ~0.03 D / SD 0.12-0.18 D 是官方全量版与临床结果之间的差异量级，不是 ALK 简化版与官方全量版之间的差异。
- 按题面合格线（mean 约 0.03 D、SD 0.12-0.18 D）衡量：纯 ALK 版 SD=0.339 D，不达标；五参数近似版 mean=+0.002 D、SD=0.164 D，落在量级内，但它依赖 ACD/LT/WTW，不是题面要求的纯 ALK 版。
- grids.npz:AL_K 曲面存在约 +0.68 D 的整体偏移，且 README 未记录该曲面的 ACD/LT/WTW/A-constant 基线；因此对该曲面同时报告原始与去均值（形状）指标。

## 3. 公式出处审计（重要）

### 3.1 任务书引用的论文

2026-10-24 实测检索结果：
- PubMed Clin Exp Ophthalmol[Journal] AND 2021[pdat] AND 49[volume] AND 7[issue] 返回 18 条，660-670 页分别被 652-663（nAMD 综述）和 664-671（gender differences）占据，没有本论文。
- Crossref 按标题、作者、年份过滤均无匹配；Wiley 卷 49 期 7 目录同样没有该标题。
- 真实的 Barrett 理论公式文献是 1993 年 JCRS 论文（PMID 8271166, doi:10.1016/S0886-3350(13)80339-2），其全文在 LWW/Europe PMC 均为付费/无全文。
- 结论：不能声称按该 2021 论文实现；报告与代码均按此如实标注。

### 3.2 社区参考实现

- Wingman4l7/catcalc 的 Barrett_Universal_II_Formula.py 是 Selenium 填表脚本，没有公式系数；无法用于数值对数。
- wcgBarrett 在 GitHub API（用户 404）和 PyPI（404）均不存在；任务书所述仓库无法验证。
- 官方 BUII 的 ELP 是未公开的三阶多项式回归；Barrett 2024 章节明确写明最简实现约 750 行、完整版约 3000 行，因此不存在可公开复刻的单页公式。

### 3.3 本模块真正实现的内容

- 聚散度核心：P = 1336/(AL-ELP) - 1336/(1336/K' - ELP)，K' 为目标屈光度经 12 mm 顶点距离折算后的角膜平面屈光度。该式即 Fyodorov/Barrett 系列的理论基础（EyeWiki 与 Alcon 白皮书均给出）。
- A-constant <-> LF：用厂商公开的四组常数对 (118.7,1.73)/(119.0,1.88)/(119.1,1.94)/(119.3,2.04) 做线性最小二乘，得到 LF = 0.518667*A -59.836800。
- ELP：在公开网格上用薄透镜反演得到等效 ELP，再对 AL/K 做二次、对 ACD/LT/WTW 做线性回归。系数是 CALIBRATED（非官方）。
- 参考对照：SRK/T（Retzlaff 1990）与 Holladay 1（1988）按公开公式独立实现，用于给离线 BUII 一个第三方包络。
- 本报告不包含实时官网对照；报告的官方输出值全部来自公开数据集。

## 9. 三方对数说明

任务书要求与 catcalc / wcgBarrett 做三方对数，但：
1. catcalc 没有 BUII 公式（只有 Selenium 填表）；
2. wcgBarrett 在 GitHub/PyPI 不存在；
3. 官方 BUII 不公开 ELP 系数。
因此改为与两个独立公开公式（SRK/T、Holladay 1）在同一批 scans 上对照，指标见第 5 节。离线模型在这批数据上优于三代表；但这只能说明聚散度核心与校准方向正确，不能证明与官方 BUII 等价。

## 10. 结论

1. 离线模块是一个近似实现：五参数模式在公开 scans 留出集上 median|Δ|=0.091 D、p95|Δ|=0.328 D；纯 ALK 模式 median|Δ|=0.159 D、p95|Δ|=0.685 D。
2. 它不是官方 BUII 的等价复刻：没有官方 ELP 系数，也没有官方厚透镜主平面迭代；短眼/长眼和高低 K 端的偏差更大。
2b. 按题面合格线，纯 ALK 版不达标（SD=0.339 D > 0.18 D）；五参数近似版达标（SD=0.164 D），但必须提供 ACD/LT/WTW。
3. 论文适用域外（AL<22 或 >26 mm、K<38 或 >48 D）只降置信度并在结果里返回 LOW_CONFIDENCE，不拒绝计算；临床使用前必须人工复核。
3b. 目标屈光度按标准 12 mm 顶点距离折算；公开网格只有 target=0，因此非零目标的数值准确性没有外部数据验证。
4. 如果拿到官方系数或论文全文，只需替换 ELP 常量并在同一脚本上重跑，即可得到真正的包络报告；当前版本的正确定位是默认离线近似 + online 显式降级/对照。
